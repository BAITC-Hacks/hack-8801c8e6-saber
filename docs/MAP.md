# Интерактивная карта Астаны

Карта использует реальные географические границы OpenStreetMap и **синтетические показатели организаторов**. Красный район означает проблему в учебном сценарии; это не оценка реального района и не официальная карта акимата.

## Что проверить на демонстрации

1. Нажать «Загрузить пример». В режиме «До решений» Нура красная: D = 49,18, два критических показателя.
2. Нажать «Сравнить» над картой. Через 1,7 секунды режим меняется на «После решений»: Нура жёлтая, D = 52,96, критических показателей нет. Цвета и полосы меняются плавно; повторное нажатие останавливает сравнение.
3. Выбрать «Эффект»: подпись Нуры показывает +3,78. Это изменение балла района, а не общего Score города.
4. Выбрать показатель «Поликлиники и первичная медпомощь»: у Нуры 35 до и 43,75 после, эффект +8,75.
5. Нажать район или его кнопку под картой. Карточка показывает значения по пяти направлениям, проблемы и результат. «Обзор районов» возвращает обзор; масштабирование и перемещение доступны отдельно.
6. Нажать «Сарайшык»: видны реальные границы и «Нет данных модели». Район не добавляется в расчёт и не получает вымышленный балл.
7. Изменить одно решение: карта автоматически получает новый результат `/api/simulate`. Пока запрос идёт или завершился ошибкой, показана база с явной подписью, старое сравнение прекращается.

## Источники и лицензии

- Подложка: стандартные тайлы [OpenStreetMap](https://www.openstreetmap.org), только для текущего видимого участка. Соблюдаются [правила использования тайлов](https://operations.osmfoundation.org/policies/tiles/): видимая атрибуция, HTTPS, стандартное браузерное кэширование, без предзагрузки или скачивания города.
- Границы: `static/data/astana-districts.geojson`, снимок шести OSM relations. В файле сохранены дата получения, ID, версия и дата каждого объекта. Координаты WGS84, GeoJSON MultiPolygon, включая отдельные части и отверстия. Источник — © OpenStreetMap contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) / [условия атрибуции](https://www.openstreetmap.org/copyright). Исходные объекты доступны по ссылкам ниже.
- Отрисовка: [Leaflet 1.9.4](https://leafletjs.com/download.html), локальная копия в `static/vendor/leaflet/`, BSD-2-Clause (`LICENSE`). JS и CSS сверены с официальными SHA-256. CDN, API-ключ карты и npm не требуются.
- Сарайшык — отдельный район города; [сообщение акимата о его создании](https://www.gov.kz/memleket/entities/astana/press/news/details/791094?lang=ru). Учебный набор содержит пять районов и остаётся неизменным. Сопоставление по названию служит только визуализации: показатели и доли населения не пересчитаны под современные границы.

Обновление снимка по явной команде (Python, стандартная библиотека):

```bash
python scripts/update_map_data.py
node --test tests/map.test.cjs
```

Скрипт получает шесть relations через OSM API, собирает пути по общим узлам, проверяет замкнутость, распределяет внутренние кольца, нормализует ориентацию и вычисляет точку подписи внутри района. Файл заменяется только после успешной обработки всех шести районов. Если OSM изменит структуру или границы, новый снимок нужно просмотреть перед публикацией.

## Поведение и ограничения

- `static/city-map.js` — изолированный слой представления. Баллы, эффекты и критичность определяются ответом движка; Leaflet не участвует в математической модели. Карта и карточки ниже используют один выбранный показатель и район.
- Для D: красный `< 50`, жёлтый `50–60`, зелёный `> 60`. Для отдельного показателя красный `< 40`. Пульсация обозначает критический показатель выбранного момента; знак `!` и текст дублируют цвет. Эффект — разница после/до: зелёный рост, розовый снижение, серый отсутствие изменений. Район без данных остаётся без рейтинга во всех режимах.
- Пять полос карточки — простые средние показателей соответствующих направлений, подписаны для вспомогательного сравнения. Итоговый D продолжает рассчитываться с весами движка.
- Библиотека и GeoJSON локальные: границы, подписи и цвета работают без доступа к внешней сети при доступном сервере. Улицы требуют `tile.openstreetmap.org`; при ошибке появляется сообщение, расчёты продолжают работать. При недоступности самого GeoJSON доступна отдельная повторная загрузка карты, основной сценарий остаётся доступен ниже.
- Поддержаны клавиатурные кнопки выбора районов, текстовая легенда, ARIA-состояния, мобильный экран и `prefers-reduced-motion`. Масштабирование колесом отключено, чтобы карта не мешала прокрутке страницы. Начальный обзор включает все шесть подписей; удалённые окраины доступны перемещением и уменьшением масштаба.
- На публичном сайте с большой нагрузкой потребуется подходящий поставщик тайлов либо своя инфраструктура; стандартный OSM-сервер не предоставляет SLA.

Проверки: `tests/map.test.cjs` — пороги, режимы времени, изменения, пропуски, критичность, направления, геометрия и подписи. `tests/frontend.test.cjs` дополнительно проверяет сброс старых цветов при изменении плана и защиту от устаревшего ответа.
